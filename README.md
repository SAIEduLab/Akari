# あかり（Akari）

あかりは、子どもが考えた場面を日本語の文で表し、同じ作品をコードとブロックの両方から編集するプログラミング環境です。「ねこは、いまのばしょから、右へ10歩動く」「ねこを、いまのばしょから、右へ10歩動かす」のように、だれが・どちらへ・どれだけ動くかを文の役割で表す言語設計を採用しています。画面の言葉は、小学3年生が一人で読めるように、3年生までに習う漢字とやさしい言葉でそろえています。

## できること

- 日本語の文から、だれが動くか・順序・きまり（条件）・範囲を表す
- 同じ本文を、コードと、文として読めるブロックの間で編集する
- へんすう・リスト・名前付きの「入れるもの」（引数）・「自分で作ったブロック」（動作と、答えを出す計算）を使う
- 計算、たんい付きの数、きまり、くり返し、いくつものキャラクターの動きを組み合わせる。この中だけのへんすう、持ち主（自分の・作品の）の指定、自分自身を使うブロック（再帰）も扱う
- 絵・すがた・はいけい・音・ペン・コピー、しつもん・合図、ようすを「しらべる」ブロックを扱う
- 部品が部品や画面のはしにふれたときに動く本文（「「星」にふれたとき、」「画面のはしにふれたとき、」）を書く
- ばしょは画面の左下のはしを よこ0・たて0 とし、右と上へ大きくなる。部品のばしょはまん中、向きは右が0度・上が90度の左回りで、算数のグラフと同じ向きで考えられる
- 作品を保存して開き直し、1つのHTML（「うごく作品を ファイルにする」）にする。インターネットなしで使えることと、資源の上限も仕様の対象に含む

## 製品の目的と対象

子どもが思い描いた場面を、主語・助詞・量・方向・時間・述語と文のまとまりで表し、文どおりの動きと比べて直すことを目指します。ブロックは作文を手で組み立て、コードは同じ作文を直接書く道具です。対象は初めて作品を作る小学生から、きまり・へんすう・自分で作ったブロック・絵や音へ学びを進める利用者です。レベル（ブロックでは「はじめて」「かんたん」「くわしく」、コードでは「かんたん」「くわしく」「名人」）を選んでも、作品と言語の意味は変わりません。

作文例と独立意図コーパスは成人が作った仮説です。実児童の観察、学習効果、学年への適合性、Scratchより使いやすいという実測上の優位は未実証です。国語の語句の役割と関係を意識する方針は、[学習指導要領解説 国語編の第3・第4学年](https://www.mext.go.jp/component/a_menu/education/micro_detail/__icsFiles/afieldfile/2019/03/18/1387017_002.pdf#page=86)を参考にしています。製品への認定や推奨を表すものではありません。能力と編集の保証、検証の区分は[監査契約](./AUDIT.md#実行区分と合格条件)に定めます。

## 使い方

レベルの設定がない初回は、ブロックの「はじめて」で開きます。左のブロック、中央の編集、右の作品とキャラクターから作り始められます。このブラウザーに残した「かんたん」「くわしく」はそのまま使います。「見せ方」は「コード」「ブロック」の切りかえだけを指し、選べるレベルは見せ方で決まります。「はじめて」のあいだは「コード」「ブロック」の切りかえを出しません。名人モードには、コードで「名人」を選んで入ります。「いっしょに作る」を押すと、「さかなキャッチ」を作り、動き・ゲーム・音やすがたを足していく案内が始まります。途中でやめても作品は残ります。最後は通常の「保存（ほぞん）」を行い、「ほぞんした作品をたしかめる」で保存した作品ファイルを選んで内容を確かめます。

画面のきっかけの名前は「「動かす」を おしたとき」「おされたとき」「キーを おしたとき」「合図を 受けたとき」「はいけいが かわったとき」「中身が かわったとき」「コピーが できたとき」「ふれたとき」「画面のはしに ふれたとき」です。「はじめて」の入口ボタンは「「動かす」を おしたとき」と、選んでいるものの名前を出した「「たくどん」が おされたとき」です。作る画面には「▶ 動かす」だけがあり、動かす画面には「▶ 動かす」がなく「■ 止める」があります。ブロックの一覧のつなぐブロックを押すと、選んでいるブロックのすぐ後ろ（何も選んでいなければ本文のいちばん下）に入ります。新しい「決めたばしょへ行く」ブロックには、選んだ部品の今のまん中のばしょが入ります。ブロックのなかま「よく使う」は、お手本の改造に使うブロックを先に並べます。「はじめて」にないブロックがある作品もそのまま残し、「かんたん」「くわしく」に切り替えて編集できます。

製品の表示バージョンは **あかり 1.5.0** です。現行製品は [`Akari_1_5_0.html`](./Akari_1_5_0.html) です。公開入口の案内に沿って開きます。初期作品と「新しく作る」の本文は空です。「お手本を開く」で、絵と短い説明がある6枚のカードから例を選びます。まだ保存していない変更があるときは、先に確認します。カードを押すと読み込み、選ぶ画面を閉じるだけなら今の作品を保ちます。ダンス・花もよう・星のゲーム・めいろ・曲づくり・お話を「▶ 動かす」で試し、数やブロックを変えて動きと比べられます。日本語文法と画面の言葉は仕様に基づくもので、児童による使いやすさの実測や、実装の受入試験を完了したという意味ではありません。

コードの言葉は、漢字の書き方（`今の場所から、右へ10歩動く`、`乱数（1、6）`、`背景を「空色」にする`、`姿をかくす`、`点数を1増やす`、`ほかの実行をすべて止める` など）と、やさしい書き方（`いまのばしょから、右へ10歩動く`、`1から6のどれか`、`はいけいを「空色」にかえる`、`すがたをかくす`、`点数を1ふやす`、`ほかの動きを全部止める` など）の両方を読みます。どちらで書いても意味は同じです。「コードを整える」と、ブロックから作る文は、やさしい書き方を使います。動きの文の書き方は LANGUAGE.md の「動きの文」、読まない書き方と直し方は「読めない書き方」にあります。

### 作品ファイルの形式

保存した作品ファイル（`.akari.md`）は、同じ作品形式のあかりでだけ開けます。前のあかりで保存したファイルは開けず、「前の あかりで ほぞんした 作品なので、この あかりでは 開けないよ。その 作品を 作った ときの あかりで 開いてね。」（F502）と表示して、今の作品はそのまま残します。形式の自動変換はしません。ブラウザー内の自動保存も形式ごとに分かれているため、前のあかりが自動保存した作品は、このあかりでは復元の対象になりません。番号は LANGUAGE.md の「保存・実行データの契約と検証」にあります。前のあかりで作った「うごく作品」のファイル（.html）は、そのまま動きます。

音声の取り込み形式は MP3 / WAV（PCM）/ M4A（AAC-LC）/ FLAC / Ogg Opus を仕様対象とします。ファイル単体での動作、保存・復元、ブラウザーごとの対応は、製品監査で確認します。

## ドキュメント

- [`Akari_1_5_0.html`](./Akari_1_5_0.html) — あかり本体（[`src/`](./src/) から `node src/build.mjs` で生成）
- [`LANGUAGE.md`](./LANGUAGE.md) — 操作方法・文法・言語仕様
- [`index.html`](./index.html) — 紹介・本体・マニュアルへの公開入口
- [`MANUAL.html`](./MANUAL.html) — はじめかた・保存・開く・うごく作品のファイル・困ったとき
- [`Manual/`](./Manual/) — [ブロック](./Manual/block-mode.html)・[コード初級](./Manual/code-mode-beginner.html)・[中級](./Manual/code-mode-intermediate.html)・[上級](./Manual/code-mode-advanced.html)・[名人モード](./Manual/meijin-mode.html)
- [`AUDIT.md`](./AUDIT.md) — 検査項目と受入基準の正本
- [`EXTENSIONS.md`](./EXTENSIONS.md) — fork開発者向けの拡張登録・外部接続・実例
- [`audit/LANGUAGE_FORMS.md`](./audit/LANGUAGE_FORMS.md) — 文型コーパスの基準 coverage と、作文文法との対応
- [`LICENSE`](./LICENSE) — ライセンス

言語仕様の正本は `LANGUAGE.md`、監査契約の正本は `AUDIT.md` です。言語契約・runtime契約・プログラム形式・作品形式の番号と自動保存の保存先の名前は、製品の表示バージョンとは独立しており、`LANGUAGE.md` の「保存・実行データの契約と検証」に定めます。製品の合否、実ブラウザー試験、児童の作文・操作評価は区別して報告します。READMEや仕様上の例は、それだけで実装PASSを示しません。

単体HTMLでオフライン利用できることは製品仕様の対象です。実際の利用条件を確認するときは、監査済みの製品と配布物を参照してください。マニュアルも保存する場合は `MANUAL.html` と `Manual/` を同じ配置で保存します。

標準の画面・機能・制限を保ちながら、forkが命令・計算・できごと、資源上限のプロファイル、別ウィンドウとの接続を組み込める土台を用意しています。本家は拡張を登録せず、通信を開始しません。拡張の実装と通信先はforkの開発者が管理します。
