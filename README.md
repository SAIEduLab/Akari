# あかり（Akari）

あかりは、SAIELが作成している、自然な日本語でプログラムを書ける学習用プログラミング言語です。

ブロックを組み立てて考えることも、コードを書いて考えることもできます。
学習の段階や目的に合わせて、**ブロックモードとコードモードを切り替えながらプログラミングできる**ことが、あかりの大きな特徴です。

## 特徴

### ブロックとコードを切り替えられる

あかりでは、同じ作品をブロックモードとコードモードの両方から編集できます。

最初はブロックで処理の流れをつかみ、慣れてきたらコードで書いてみる、といった使い方ができます。

「ブロックプログラミング」と「コードを書くプログラミング」を別々のものとして学ぶのではなく、行き来しながら理解を深められることを目指しています。

### 自然な日本語で書ける

コードモードでは、日本語に近い形でプログラムを書くことができます。

英語の命令を覚えることよりも、プログラムの考え方そのものに集中しやすい言語を目指しています。

### スタンドアローンで使える

`Akari.html` は単一のHTMLファイルとして動作します。

外部通信を使用しないため、インターネット接続のない環境でも利用できます。

特別なサーバーやオンラインサービスを用意する必要はなく、対応するブラウザーがあれば動かせます。

## 使い方

本体は **あかり1.0.0** です。[公開入口](./index.html)から本体とマニュアルへ進めます。

1. `Akari.html` を端末に保存し、ブラウザーで開きます。
2. 「▶ 動かす」を押し、マスコットをクリックして動きを試します。「■ 止める」で編集へ戻ります。
3. 自分の作品を作ったら「保存」で `.akari.md` を残します。続きはあかりの「開く」から読み込みます。

完成した作品を編集画面なしで動かすには「書き出し」で単体HTMLを作ります。手順とファイルの使い分けは[マニュアル](./MANUAL.html#save)を参照してください。

インストールやアカウント登録は必要ありません。
