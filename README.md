# あかり（Akari）

あかりは、子どもが考えた場面を日本語の文で表し、同じ作品をコードとブロックの両方から編集するプログラミング環境です。「ねこは画面の右へ10歩動く」「ねこを画面の右へ10歩動かす」のように、だれが・どちらへ・どれだけ動くかを文の役割で表す言語設計を採用しています。画面の言葉は、小学3年生が一人で読めるように、3年生までに習う漢字とやさしい言葉でそろえています。

## できること

- 日本語の文から、だれが動くか・順序・きまり（条件）・範囲を表す
- 同じ本文を、コードと、文として読めるブロックの間で編集する
- へんすう・リスト・名前付きの「入れるもの」（引数）・「自分で作ったブロック」（動作と、答えを出す計算）を使う
- 計算、たんい付きの数、きまり、くり返し、いくつものキャラクターの動きを組み合わせる。この中だけのへんすう、持ち主（自分の・作品の）の指定、自分自身を使うブロック（再帰）も扱う
- 絵・すがた・はいけい・音・ペン・コピー、しつもん・合図、ようすを「しらべる」ブロックを扱う
- 作品を保存して開き直し、1つのHTML（「うごく作品を ファイルにする」）にする。インターネットなしで使えることと、資源の上限も仕様の対象に含む

## 製品の目的と対象

子どもが思い描いた場面を、主語・助詞・量・方向・時間・述語と文のまとまりで表し、文どおりの動きと比べて直すことを目指します。ブロックは作文を手で組み立て、コードは同じ作文を直接書く道具です。対象は初めて作品を作る小学生から、きまり・へんすう・自分で作ったブロック・絵や音へ学びを進める利用者です。見せ方（はじめて・かんたん・くわしく）を選んでも、使える能力は減らしません。

作文例と独立意図コーパスは成人が作った仮説です。実児童の観察、学習効果、学年への適合性、Scratchより使いやすいという実測上の優位は未実証です。国語の語句の役割と関係を意識する方針は、[学習指導要領解説 国語編の第3・第4学年](https://www.mext.go.jp/component/a_menu/education/micro_detail/__icsFiles/afieldfile/2019/03/18/1387017_002.pdf#page=86)を参考にしています。製品への認定や推奨を表すものではありません。能力と編集の保証、検証の区分は[監査契約](./AUDIT.md#実行区分と合格条件)に定めます。

## 使い方

見せ方の設定がない初回は「はじめて」で開きます。左のブロック、中央の編集、右の作品とキャラクターから作り始められます。保存済みの「かんたん」「くわしく」はそのまま使います。「いっしょに作る」を押すと、「さかなキャッチ」を作り、動き・ゲーム・音やすがたを足していく案内が始まります。途中でやめても作品は残ります。最後は通常の「保存（ほぞん）」を行い、「ほぞんした作品をたしかめる」で保存した作品ファイルを選んで内容を確かめます。

画面のできごと名は「「動かす」を おしたとき」「おされたとき」「キーを おしたとき」「合図を 受けたとき」「はいけいが かわったとき」「中身が かわったとき」「コピーが できたとき」です。「はじめて」の入口ボタンは「「動かす」を おしたとき」「キャラが おされたとき」です。通常の編集でも、入れる場所を選ばずに道具箱のつなぐブロックを押すと、いま開いている本文のいちばん下に入ります。新しい「ばしょへ行く」ブロックには、選んだ部品の今のばしょが入ります。ブロックのなかま「よく使う」は、お手本の改造に使うブロックを先に並べます。「はじめて」にないブロックがある作品もそのまま残し、「かんたん」「くわしく」に切り替えて編集できます。

製品の表示バージョンは **あかり 1.3.1** です。現行製品は [`Akari_1_3_1.html`](./Akari_1_3_1.html) です。公開入口の案内に沿って開きます。初期作品と「新しく作る」の本文は空です。「お手本を開く」で、絵と短い説明がある6枚のカードから例を選びます。まだ保存していない変更があるときは、先に確認します。カードを押すと読み込み、選ぶ画面を閉じるだけなら今の作品を保ちます。ダンス・花もよう・星のゲーム・めいろ・曲づくり・お話を「▶ 動かす」で試し、数やブロックを変えて動きと比べられます。日本語文法と画面の言葉は仕様に基づくもので、児童による使いやすさの実測や、実装の受入試験を完了したという意味ではありません。

コードの言葉は、漢字の書き方（`横100、縦50の位置へ行く`、`乱数（1、6）`、`背景を「空色」にする`、`姿をかくす`、`ほかの実行をすべて止める` など）と、やさしい書き方（`よこ100歩、たて50歩のばしょへ行く`、`1から6のどれか`、`はいけいを「空色」にかえる`、`すがたをかくす`、`ほかの動きをぜんぶ止める` など）の両方を読みます。どちらで書いても意味は同じです。「コードを整える」と、ブロックから作る文は、やさしい書き方を使います。

### 作品ファイルの形式

保存した作品ファイル（`.akari.md`）の形式は3です。形式の違うファイル（形式が3になる前のあかりで保存したファイルなど）は開けません。開こうとすると「前の あかりで ほぞんした 作品なので、この あかりでは 開けないよ。」（F502）と表示し、今の作品はそのまま残します。形式の自動変換はしません。ブラウザー内の自動保存も形式ごとに分かれているため、以前のあかりが自動保存した作品は復元の対象になりません。

音声の取り込み形式は MP3 / WAV（PCM）/ M4A（AAC-LC）/ FLAC / Ogg Opus を仕様対象とします。ファイル単体での動作、保存・復元、ブラウザーごとの対応は、製品監査で確認します。

## ドキュメント

- [`Akari_1_3_1.html`](./Akari_1_3_1.html) — あかり本体（[`src/`](./src/) から `node src/build.mjs` で生成）
- [`LANGUAGE.md`](./LANGUAGE.md) — 操作方法・文法・言語仕様
- [`index.html`](./index.html) — 紹介・本体・マニュアルへの公開入口
- [`MANUAL.html`](./MANUAL.html) — はじめかた・保存・開く・うごく作品のファイル・困ったとき
- [`Manual/`](./Manual/) — [ブロック](./Manual/block-mode.html)・[コード初級](./Manual/code-mode-beginner.html)・[中級](./Manual/code-mode-intermediate.html)・[上級](./Manual/code-mode-advanced.html)
- [`AUDIT.md`](./AUDIT.md) — 検査項目と受入基準の正本
- [`EXTENSIONS.md`](./EXTENSIONS.md) — fork開発者向けの拡張登録・外部接続・実例
- [`audit/LANGUAGE_FORMS.md`](./audit/LANGUAGE_FORMS.md) — 文型コーパスの基準 coverage と、作文文法との対応
- [`LICENSE`](./LICENSE) — ライセンス

言語仕様の正本は `LANGUAGE.md`、監査契約の正本は `AUDIT.md` です。仕様上の `languageContractId`・`runtimeContractId`・`programFormatVersion` はそれぞれ2、`projectFormatVersion` は3で、製品の表示バージョンとは独立しています。自動保存の領域名は `akari-workspace-f3` と `akari.autosave.f3` です。製品の合否、実ブラウザー試験、児童の作文・操作評価は区別して報告します。READMEや仕様上の例は、それだけで実装PASSを示しません。

単体HTMLでオフライン利用できることは製品仕様の対象です。実際の利用条件を確認するときは、監査済みの製品と配布物を参照してください。マニュアルも保存する場合は `MANUAL.html` と `Manual/` を同じ配置で保存します。

標準の画面・機能・制限を保ちながら、forkが命令・計算・できごと、資源上限のプロファイル、別ウィンドウとの接続を組み込める土台を用意しています。本家は拡張を登録せず、通信を開始しません。拡張の実装と通信先はforkの開発者が管理します。
