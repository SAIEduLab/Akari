# あかり 0.8 — 使い方・言語仕様

この文書は、あかり 0.8 の使い方と、日本語の標準文型・実行意味を定める利用者向け仕様の正本です。

実際に受理される文法・名前・対象は `Akari.html` のパーサーと検査処理が基準です。

## はじめに：最初の作品を動かす

あかりは、日本語の定型文で画面上の部品を動かすプログラミング環境です。このHTMLだけで編集・実行できます。まず「実行」を押して星をクリックすると点数が増えます。「停止」で編集に戻ります。道具箱の部品をクリックして追加し、画面上でドラッグして配置します。名前・大きさ・色はプロパティで編集します。部品を選んでDeleteキーを押すと削除します。文字入力中は削除されません。

## 書く場所と実行の順序

「対象」で画面または部品、「できごと」で実行のきっかけを選び、本文だけを書きます。一つのできごとには一つの本文を登録できます。開始時は画面、部品の登録順に処理が作られます。複数の処理は命令単位で順番に実行され、待っている処理以外は進みます。開始の本文が終わっても、停止するまでクリックなどを受け付けます。命令は通常、選んだ対象自身に作用します。

## 日本語の書き方

1行に1命令またはブロック開始文を書きます。人間には自然な日本語として読め、機械には意味が一意になる定型文を使います。主語・対象の省略は、選択した実行対象から一意に決まる場合に限ります。

「もし 条件なら、次のことをする」「次のことを3回くり返す」などに続く本文は、半角スペースで深く字下げします。同じブロックの文は同じ字下げ位置にそろえます。字下げを戻すとブロックが終わり、存在しない位置への戻りはエラーです。最上位は字下げしません。タブ・全角空白による字下げは禁止です。入力幅は任意ですが、「コードを整える」は1段を半角スペース2個にします。空行・コメント行は範囲を変えません。空の処理を書く場合は、本文に「何もしない」を置きます。この文は1命令を進め、状態を変更しません。

ブロック開始文の後でEnterを押すと、次の行を自動で字下げします。日本語IMEの変換中には自動字下げしません。Tabはフォーカス移動に使います。「そうでなければ、次のことをする」は、直前の同じ字下げ位置の「もし」にだけ対応します。一行形式の条件分岐はありません。

文末の「。」は省略して入力できますが、整形では付けます。反復の「繰り返す」は「くり返す」へ整えます。文字は「こんにちは」のようにかぎ括弧で囲み、1行で書きます。文字列内部の「」を表すエスケープ記法はありません。※から行末まではコメントですが、文字列内の※は文字です。演算子・括弧・数字は全角と対応する半角を使えます。文字列内の表記は整形で変更しません。

0.7のブロック終端「ここまで」は受理しません。範囲は字下げで表します。

## 名前・変数・リスト

作品全体または各部品のデータは「データ」で先に作ります。変数には数・文字・真偽、リストにはそれらの並びを入れます。入れ子のリストは使えません。名前は1〜32文字で、空白・括弧・制御文字・予約語などは使えません。普通の名前は「点数」のようにそのまま書けます。助詞や演算子を含む名前、数字で始まる名前、「端」「空白」など固定の語と同じ名前は【手がかり】・【端】のように囲みます。「自分の点数」「作品の【手がかり】」で所属を明示できます。読取りの優先順位は反復の項目名、局所データ、引数、個体データ、作品データです。名前の区切りは登録数によって変わりません。「データ」と入力候補で実際の書き方を確認でき、整形では必要な名前だけ【】を付けます。次の実行は初期値から始まります。

```text
点数を0にする
点数に1を足す
点数から1を引く
名前一覧に「あかり」を追加する
名前一覧の1番目を「ひかり」にする
名前一覧の1番目に「ほたる」を挿入する
名前一覧の1番目を削除する
名前一覧を空にする
```

## 条件分岐と反復

条件は真または偽になる式です。比較は「が〜以上／以下／より大きい／より小さい／と同じ／と違う」、組合せは「かつ／または」、否定は「ではない」です。「かつ」「または」は必要な側だけを評価します。複合条件や任意の真偽式を使う条件反復・待機では「条件（…）が成り立つ」という名詞＋述語の形にします。「まで」は条件が真になったら終了し、最初から真なら本文を実行しません。回数は開始時に一度だけ評価する0以上の整数です。

```text
もし 【点数】が10以上なら、次のことをする。
  「10点以上です」と言う。
そうでなければ、次のことをする。
  「10点未満です」と言う。
次のことを10回くり返す。
  【点数】に1を足す。
条件（【点数】が100より小さい）が成り立つあいだ、次のことをくり返す。
  【点数】に1を足す。
条件（「空白」キーが押されている）が成り立つまで、次のことをくり返す。
  0.1秒待つ。
条件（【点数】が100以上）が成り立つまで待つ。
```

## 短い条件文でくり返す・待つ

簡単な条件は下の短い形で書けます。反復は「、次のことをくり返す」を末尾に付けて本文を字下げします。「以上・以下・と同じ」は「であるあいだ」「になるまで」、「より小さい・大きい」は「あいだ」「小さく・大きくなるまで」とつなぎます。条件は本文の前に判定します。「待つ」の間もほかの処理は進みます。接触条件は部品上で使います。

```text
点数を0にする。
点数が3より小さいあいだ、次のことをくり返す。
  点数に1を足す。
点数と言う。

空白キーが押されるまで待つ。
空白キーが押されなくなるまで待つ。
※ 部品上の例：端に触れるまで待つ
```

## リストを一つずつ処理する

反復開始時のリストを複製し、先頭から順に一つずつ処理します。項目名は本文の中だけで使える読み取り専用の名前です。空のリストなら本文を実行しません。途中で元のリストを変更しても、その反復の順番と内容は変わりません。番号は1から数えます。範囲外の読込・更新・削除はエラー、挿入だけは末尾の次の番号も使えます。

```text
名前一覧の各要素を項目として、次のことをくり返す。
  項目と言う。
※ 内側の反復を終了する：このくり返しを終える
※ 内側の反復の次の回へ：次のくり返しへ進む
```

## 数・文字・式

数は有限の数値だけを扱い、暗黙の文字変換はしません。四則演算は＋－×÷、累乗は＾、括弧は（）。累乗は右結合で、単項符号より優先します。次に乗除、加減、比較、否定、かつ、またはの順です。数（文字）で数に、文字（値）で文字に変換します。乱数（下限、上限）は両端が整数なら両端を含む整数です。「つなぐ」は2個以上の数・文字・真偽を連結します。長さと文字位置はUnicodeのコードポイント単位です。

```text
2＋3×4
（2＋3）×4
乱数（1、10）
余り（10、3）
つなぐ（「点数：」、【点数】）
【名前一覧】の長さ
【名前一覧】の1番目
「こんにちは」の文字数
「こんにちは」の2文字目
【名前一覧】に「あかり」が含まれている
【名前一覧】で「あかり」が最初にある番号
```

## 動き・見た目・ペン

座標は画面左上が横0・縦0で、右と下が正です。部品の横位置・縦位置は回転前の左上です。方向0度は右、90度は下。1歩と座標の1は1ピクセルで、ペンの太さもピクセル単位です。距離は中心間の距離です。接触判定は回転と拡大を含む外接長方形で、透明な画素の形そのものではありません。動き・ペンは部品で使い、衣装・クローンはスプライトだけで使います。ペンは部品の中心を通ります。「描いた線とスタンプを消す」は画面全体の描画を消します。色は「赤」などの色名または「#ff0000」の形式です。

```text
10歩動く
横100、縦50の位置へ行く
1秒で横200、縦100の位置へ滑る
右に15度回る
左に15度回る
方向を90度にする
横位置を100にする
縦位置を50にする
「マウス」の方向を向く
端に触れていれば跳ね返る
大きさを120％にする
表示色を「赤」にする
隠れる
現れる
前面へ出す
背面へ下げる
1層前へ出す
1層後ろへ下げる
ペンを下ろす
ペンの色を「青」にする
ペンの太さを3にする
ペンを上げる
スタンプを押す
描いた線とスタンプを消す
```

## 素材・文字・入力欄

「素材」で背景・スプライトの衣装・音を追加します。画像はPNG/JPEG/WebP、音はMP3/WAV。画像は元のPNG/JPEG/WebP形式で再エンコードし、素材を作品内に埋め込みます。文字の変更は文字・ボタン・四角に使い、入力欄には文字を入れます。画像の表示色を変更しても画像自体の色は変わりません。名前で指定する部品は元の部品を指します。

```text
背景を「空色」にする
次の背景にする
前の背景にする
衣装を「星」にする
次の衣装にする
前の衣装にする
「ボタン1」の文字を「始める」にする
※ 入力欄を作ってから使う例：
※ 「入力欄1」に「こんにちは」を入れる
※ 「入力欄1」の値と言う
```

## 音と待機

「鳴らす」は音を開始して次の命令へ進み、「鳴らし、終わるまで待つ」はその再生が終わるまで現在の処理だけを待たせます。ほかの音の終了は待ちません。「すべての音を止める」で音待ちも解除します。音量は0〜100％、音程は1段階が半音です。一時停止では論理時計と音声を一時停止します。音声装置の切替は非同期で行われます。

```text
440Hzの音を0.2秒鳴らす
440Hzの音を0.2秒鳴らし、終わるまで待つ
音量を50％にする
音程を1段階上げる
音程を1段階下げる
すべての音を止める
※ 「ベル」という音を追加した場合：
※ 「ベル」を鳴らし、終わるまで待つ
```

## 知らせ・質問・できごと

「知らせる」は画面と全個体の「知らせを受けたとき」を起動します。受け取った知らせを条件で選びます。「受け手の処理が終わるまで待つ」は、その通知で直接起動した各処理の終了を待ちます。受け手が別の通知を待たずに出した場合、その先の処理までは待ちません。自分にも通知が届くので、無条件の再通知は避けます。質問は一つずつ表示され、「答え」は質問した処理ごとに保持されます。

```text
「開始」と知らせる。
「開始」と知らせ、受け手の処理が終わるまで待つ。
「名前は？」とたずねる。
答えと言う。
※ 「知らせを受けたとき」の本文：
※ もし 受け取った知らせが「開始」と同じなら、次のことをする。
※   「受け取りました」と言う
```

## 動作と求値を作る

「動作・求値」で種類・名前・引数を登録し、本文欄には本文だけを書きます。動作は処理をまとめたもので、呼び出し元の個体で実行します。求値は値を計算して返すもので、外部データの変更・描画・待機はできません。求値の最後には「〜を返す」を一つ置きます。局所変数・リストは本文の先頭で作ります。引数は値渡しで、リストも複製されます。イベント固有の値は引数で渡してください。

```text
※ 動作「ジャンプ」、引数「高さ」の本文例
縦位置を縦位置－高さにする。
0.2秒待つ。
縦位置を縦位置＋高さにする。
※ 呼び出し：ジャンプ（30）を実行する

※ 求値「合計値」、引数「数一覧」の本文例
合計という変数を作り、初期値を0にする。
数一覧の各要素を項目として、次のことをくり返す。
  合計に項目を足す。
合計を返す。
※ 呼び出し：合計値（［1、2、3］）と言う
```

## クローン・停止・デバッグ

クローンはスプライトの実行時の複製です。個体データと見た目を複製し、作品データは共有します。「クローンされたとき」だけを新しく起動します。実行時の変化やクローンは作品の保存内容に反映しません。「一時停止」「続ける」「1命令ずつ」で調べられます。1命令ずつでも待ち時間は早送りされません。「停止」は実行状態を破棄して編集に戻ります。「最初に戻す」は現在の編集セッションの初期状態へ戻す操作です。

```text
自分のクローンを作る
「星」のクローンを作る
このクローンを削除する
このスクリプトを止める
ほかのスクリプトを止める
すべてを止める
```

## 保存・復元・書き出し

「保存」は .akari.md を作ります。本文にコード・初期データ・部品・素材一覧を表示し、末尾に復元用データを埋め込みます。Markdown本文は読むためのもので、直接編集する場所ではありません。修正はあかりの中で行い、改めて保存します。本文と復元データが一致しないファイルはF512で拒否し、現在の作品を保ちます。文法エラーがある作りかけの本文も保存できます。動作・求値の編集中の下書きは、先にその画面の「保存」で作品へ登録します。「開く」は0.8形式専用です。appVersionと言語版は0.8、保存形式と実行形式は2です。0.7以前のソース・作品ファイルの読込みや自動変換は提供しません。「書き出し」は文法・参照を検査し、編集機能を持たない単体HTMLを作ります。自動保存はこの端末・ブラウザー内だけです。動作・求値の未登録の下書きも自動保存に含め、復元後は編集を続けられます。利用できない場合や容量不足は表示します。自動保存と別にファイル保存してください。外部通信・外部スクリプトの読込みは行いません。

0.8の自動保存領域は0.7と分けて保持します。0.8の編集・復元・自動保存の消去で0.7の自動保存を上書きしません。

## 画面幅と表示縮尺

狭い画面では道具箱、デザイナ、作品一覧、プロパティ、モニター、コード欄を縦に配置します。主要操作はツールバー内で折り返します。表示段階「基本」で隠される機能は「発展」へ切り替えると利用できます。ダイアログの本文はスクロールできます。

画面デザイナは、作品に保存した論理座標を保ったまま表示だけ縮小します。ポインター位置・ドラッグ・配置を論理座標へ換算するため、画面幅だけを変えても部品の位置や大きさは変わりません。未保存コード、カーソル、選択中の部品、実行・一時停止状態も保持します。書き出した単体HTMLでも同じ縮尺処理を使います。

## エラーと上限

「作品診断」は場所・行・理由を表示します。文法・名前・対象の誤りは実行前、値の型や範囲の誤りは必要に応じて実行時に検出します。実行エラーでは一時停止し、停止して修正できます。Fはファイル、N/Pは文字と文法、Sは参照・意味、Rは実行、Xは書き出し形式のエラーです。無限ループは実行を分割するため停止できますが、求値は計算量の上限で終了します。自己検査のPASSは定義された自動検査への合格であり、すべての環境で未知の不具合がない保証ではありません。

## 入力候補で文法を探す

検索欄に語を入れ、前・次で候補のページを切り替えます。対象外の候補も表示すると、使えない理由を確認できます。命令は空の行または行全体の選択範囲に挿入し、式はカーソル位置または選択範囲に入れます。数値や文字は例なので、目的に合わせて直します。引数の型は呼出し側で決まるため、リスト操作の候補があってもリストを渡す必要があります。引数・局所値・反復の項目は挿入位置に合わせて表示します。局所宣言は本文先頭、返却は求値の末尾、反復の中断は反復内で使います。

## 失敗したときの値を調べる

実行エラーでは一時停止し、失敗記録の画面を開きます。失敗した動作・求値自身の行・命令・呼出し順・引数・局所値・作品・個体データを記録します。「全文」で長い値をページごとに、リストを要素番号ごとに読めます。続行後に現在値が変わっても失敗時の記録は変わりません。実行モニターから記録を開き直せます。保持は直近20件以内かつ記録のJSON合計8,388,608文字を目安に、古い記録から消します。最新1件はこの長さを超えても保持します。「停止」と次の実行で記録は消えます。失敗した処理は終了するため、修正後は改めて実行します。

## キーボード操作と準備中の制限

Tabで操作対象を移動します。作品の一覧は矢印・Home・Endで選び、Enterで開きます。実行開始後は実行画面にフォーカスが移ります。クリック処理のある部品やボタンはTabで選び、Enterまたは空白キーで押せます。質問のEnterは変換中には答えを送信しません。通常のダイアログはEscapeで閉じ、開いた元に戻ります。実行中・素材準備中・取込み中には作品の編集をロックします。素材の準備中は停止できますが、作品や素材の取込み中は終了まで編集操作を待ちます。画像・音の準備の応答が10秒ない場合はエラーにします。

## 読み取れる状態の一覧

`マウスが押されている` ／ `マウスの横位置` ／ `マウスの縦位置` ／ `以前の背景名` ／ `新しい背景名` ／ `受け取った知らせ` ／ `押されたキー` ／ `クローンである` ／ `背景番号` ／ `背景名` ／ `衣装番号` ／ `衣装名` ／ `横位置` ／ `縦位置` ／ `方向` ／ `大きさ` ／ `タイマー` ／ `答え` ／ `音量` ／ `音程` ／ `以前の値` ／ `新しい値`

イベント専用の値：押されたキーはキーを押したとき、受け取った知らせは知らせを受けたとき、以前の値・新しい値は入力欄の値が変わったとき、以前の背景名・新しい背景名は背景が変わったときに使います。キー名は 空白、上、下、左、右、決定、取消、a などです。色の接触は設定色と外接長方形の判定で、画像の画素やペンの描画は調べません。

## 組み込み求値の一覧

- `乱数`（引数2個）、`余り`（引数2個）
- `四捨五入`、`切り上げ`、`切り捨て`、`絶対値`、`平方根`、`正弦`、`余弦`、`正接`、`逆正弦`、`逆余弦`、`逆正接`、`自然対数`、`常用対数`、`指数`、`数`、`文字`（各引数1個）
- `最小`、`最大`（引数1個以上）
- `つなぐ`（引数2個以上）

三角関数の角度は度です。「最初にある番号」は見つからなければ0を返します。四捨五入の負の中間値は0から遠ざかる方向です。
