# 編集と自然文のUX改修・再監査契約

自動検査の成功は、独立した実操作UXの合格や児童の学習効果を意味しない。`fixtures/ux-edit-benchmark.json` は固定24課題×2モードの48枠と、本施工では対象外のScratch24枠を区別する。操作数・予測・支援・誤選択・8軸所見を観測していない枠に推測値を入れない。通常入口B22→B01〜B21→B23→B24の順で再監査する。準備で学んだ操作は初見成功にしない。

`tests/ux-edit-language.mjs` は固定原文を `fixtures/ux-edit-expectations.json` から読み、独立した時刻・話者・値の期待を比較する。原文の変更、期待値の実装出力からの自動採取、ケース削除、skipによる合格化をしない。`tests/ux-edit-browser.mjs` は固定ブラウザーで通常の入力・選択・削除・取消・実行を行い、矩形・表示値・スクリーンショットを残す。報告の `uxAcceptance` は常にfalseである。

追加回帰は部品名「今」の旧参照（部品7／作品2）、別対象・別条件、時間指定の有無が混在する順序、停止と一時停止からの再開、算術式と条件比較の値の片側変更、削除したelse穴の補完後の両分岐を確認する。吹き出しは従来の52%／100%長文に加え、52%の改行なし60・70・80字と29%の78字で実際の本文切れと全文入口を検証する。29%も他の倍率と同じ重なり条件を要求する。全文・実値のボタンは見えるラベルとaccessible nameを保持し、発話本文のtextContentへラベルが混ざらないことも検証する。

B23の固定初期状態（既存あかり開始「おはよう」＋空のだんごクリック）への原文全体の入力は、明示取り込みの必須回帰で検査する。入力・IME中の対象と本文保持、既存と追加先の日本語表示、通常の確認ボタン、既存本文のbyte保持、あかり開始1件・だんごクリック1件、だんご自身の本文への到達、元のあかり本文への復帰、実発話、取消、Undo/Redoを要求する。内容が違う場合の比較と明示的な別本文追加、現在編集中の非空本文を含む既存本文の保護、安全に分けられない依存節の拒否、意図的な同内容2本文の実行も別ケースで要求する。実行時の重複排除・文書参照規則は追加しない。原文・期待値・保存形式番号を変えない。独立UX合格は依頼元の最終実操作を待つ。

結果集約は必須レポートの全項目・最終snapshot・固定ブラウザー・原文保持を検査する。欠落レポート、欠落項目、重複項目、FAIL、別SHAを拒否する。必須本文を穴として保持するGUI経路でも、確定ソースの保持・実行拒否・取消・明示的な何もしないへの置換を検証する。通常APIの構造拒否契約は維持する。

既存`structured-editing-browser.mjs`の見出し操作は、選択のみで確定する旧手順から明示確定する手順へ移行する。既存9ケースの意味・履歴・実行期待を保持し、選択時に作品・履歴を変更しない追加検査を行う。他の既存監査・独立オラクル・workflowトリガーは維持する。

## 現在の意味と実行

現在の意味はLANGUAGEと公開意味契約、能力と独立期待値は capability-oracle / capability-traceability を参照する。原作文、意味、原文保護、保存・実行とUIを別に検証する。旧工程の復元は行わない。

CIで一つのブラウザー停止後に後続の保存ケースが実行されなかった事実を踏まえ、作文受入と素材編集の各ケースは新しいブラウザーから実行する。両スイートの総制限300000msと既存ケース・期待値は維持する。失敗時の補助画面採取は8000msで打ち切ってFAILを記録し、後続ケースの結果をブラウザー終了による失敗と混同しない。

ドラッグ端スクロールは通常の720px/秒を保ち、描画フレーム数が減っても到達速度を落とさない。従来9組の表示幅・倍率、121命令、400回の操作・20ms待ち・到達／取消／履歴期待は変更せず、実座標・経過時間・スクロール量を追加採取する。

390幅・125%の端スクロールは、端ドラッグだけを実内容の下端で止める。自由パンの余白、倍率、既存の到達・プレビュー・取消期待は保つ。取り込み下書きの作品ファイル復元に加え、自動保存からの復元でも同じ確認欄を再表示する。

現在編集中の本文を意図して変更する場合は、届いた最初の見出しが現在の対象・できごとと一致し、他の既存本文との衝突がないときに限り、既存と届いた内容を表示して「この本文を変更して取り込む」を選べます。この操作は現在の本文だけを変更し、他の本文はそのまま保ちます。既存を残す追加とは別の明示操作であり、入力だけで本文を置換しません。全文・識別子・Undo/Redoと従来の複数見出し文書の編集を保ちます。


## 通常編集・可読性の追加契約

通常幅1188pxのB01/B04/B10/B13/B15は、常設の補助操作が本文を横へ押し出さず、挿入位置をナビゲーションが覆わない。1188×848、1188×761、1366×768、1024×768、390×844で明暗設定と作業場100/75%を検査する。長い本文の縦スクロールは維持する。局所の値選択を開いても隣の値を遮蔽しない。

診断は現在の入力・変換・確定・取消・表示切替・実行・Undo/Redoと対応させる。前の不正入力の赤表示を正常な実行へ残さない。パレットは時間付きと時間なしの発話を区別し、連続追加の検索語と分類範囲を保持する。未完成の穴を持つ命令を入れた場合は、次の値を探せるよう検索語を外し、「前の検索」を一操作で戻せるようにする。検索復帰だけでは本文・履歴・選択値を変えない。

`ux-normal-matrix.json` はB01〜B24の初期状態・操作・期待をコードとブロックの48枠として検査する。質問を足す制作課題の前提と、固定された原文断片は分けて記録する。通常のGUI入力・選択・移動・取消・Undo/Redoを使い、準備用プロジェクトの投入をユーザー操作実績と混同しない。これは成人が作った機械操作であり、子どもの初見UXやScratch24枠の再実測を主張しない。

発話の追加検査は2体の端・中央配置、29/39/49/52/100%、短文3種、60/70/78/80/225文字、絵文字、改行を固定する。実効フォント、本文の可視領域、話者、重なり、全文入口のクリック後の一致、2秒で消える時刻を観測する。既存の長文6条件も別に保持する。

実行準備の失敗はエラーの種類と詳細を表示し、作品と再試行経路を保持する。故障注入による取消・古い世代の拒否・再実行の成功は、断続的な実障害の根因特定を意味しない。合成compositionと実IME、アプリ内部の処理時間と外部自動操作の待ち時間も別の観測として扱う。

既存検査の操作経路は、補助をその場で開く画面へ合わせる。時間指定は「編集」を開いて選び、単位は通常の表示1個と詳細内の編集値を分けて検査する。Undo/Redo後の全文編集は文字欄を選択して入口を表示する。旧ID・ケース数・意味・履歴・矩形・実座標クリック・時間の期待値を保持し、隠れた補助を通常表示に数えない。

局所の全文編集入口は選択した文字欄だけに表示する。可変長入力の親式を選択しただけで全子欄の補助を一斉に開かず、「次の入力」等をpointerdownとclickの間に移動させない。リスト復帰と発話データの候補は、明示された親命令・式、まとまり、画面の評価対象に一致させる。Enter後の継続入力、反復内・分岐内の同階層cut/paste、行頭・文末paste、引用・注釈内の空白保持、Undo/Redoを検査する。

全スキーマの構造操作で未完成の数欄を式として埋める場合は、命令の「編集」から「回数を式で指定」を開き、従来と同じ独立期待の式・値を選ぶ。直接数入力の追加によって、式による回数の能力・旧ケース・期待・操作制限を取り除かない。

## きっかけ・発話全文・引用リストの局所回復

きっかけ変更は「いつ動く？」から直接選ぶ基本経路と、見出し・対象・フィルターの詳細経路を分ける。現在の動きのまとまりと対象を表示し、選択だけでは保存せず明示確定・取消を保持する。空のクリック本文を選ぶ操作と、既存開始本文のきっかけをクリックへ変える操作は別に検査する。B23の明示取込み、所有先配分、複数本文、全イベント能力は既存必須群で維持する。

発話の全文には開いた話者を近接表示し、本文への名前混入を禁止する。開いた時点の表示契約、短文の直接表示、B10の2秒・1秒後の並行発話を変更しない。一般の値とリストの全文表示、同名クローンの識別を別に検査する。

引用文字列の「N番目」はR411で拒否し、同名リストへの暗黙変換をしない。失敗箇所の原文と有効な所属の候補を表示し、停止して編集へ戻った後の明示操作だけで対象の式を置き換える。本文の変更、別の実行、参照先の変更を検出して古い箇所への置換を防ぐ。Undo/Redo、取消、添字・発話時間・他の文・データの保持、明示リスト参照と既存ブロック候補を検査する。

追加3群は `tests/ux-phrase-trigger.mjs`、`tests/ux-phrase-speech.mjs`、`tests/ux-phrase-list.mjs` と各 `lib/ux-phrase-*-contract.mjs` で固定する。1180×757と1188×848、コード舞台28/29%と通常倍率の結果を区別し、集約は最終snapshotに対応する全結果を要求する。GA-STATICは登録・hash・拒否能力、GA-EXECは実ブラウザー操作と実行結果、SEMANTICは対象・意味・能力の保持、HYBRIDは表示の読解と操作への到達性を扱う。依頼元の独立監査・台帳更新をこれらの施工検証で代替しない。

## 10%表示の個別開始発話

`tests/speech-preview-browser.mjs` はかんたん・コードモードの新規作品にマスコットを追加し、各対象の開始本文へ短文を個別入力する。1180×756、リセット後の縮小9回、2秒の同時発話を、新規と同じ作業で作った自動保存の復元で検査する。元のnihongoデータを再現したとは扱わない。標準フォントに加え、WindowsはMeiryo、LinuxはNoto Sans CJK JPの全角幅の条件を明示して上下配置を実行する。

1行と横幅が既に確保された小さな短文配置では、フォントのem領域がline boxから出るだけで全文ボタンを予約しない。本文14 CSS px・名前11.2 CSS px、短文の直接表示と2秒を保つ。新規検査はscroll/client値とRangeの矩形を原値で残し、各文字の実DOM位置とCanvasのactualBoundingBoxから描画範囲も確認する。既存13件と9負例のRange・scroll条件を変更しない。

10%で長文自体が収まらない場合は、話者名と全文ボタンを組にした独立した行を舞台内に置き、全文ダイアログへ進める。短文にはこの予約を適用しない。78字の二人分の全文、コピー対象、485pxでの閲覧・閉じるを検査する。長文の10秒は読み取り専用fixtureであり、短文2秒の代替ではない。


## 実行開始と状態観測


ボタン検査は既存の素材検査と同様にケースごとの新規ブラウザーで実行する。9件・各操作・期待値・待機30000ms・スイート総制限360000msを維持し、再試行しない。終了処理より前に元の例外と段階を残し、外側の終了・制限エラーも結果JSONへ記録する。`ci-regression.mjs` は実際の実行ループへ読込み失敗・終了失敗・操作のassertion失敗を注入し、元の失敗保持・ケース分離・予算の減少と既存10負例を検査する。製品HTMLと共通ホストは変更しない。



## 児童目線UX監査への対応

B01–B24のID・意図・独立期待・復帰条件を維持して、[追加監査契約](CHILD_UX.md)に要求と既存試験の対応、往復観測、言葉の候補、代理評価・実児童・実IME・Scratch比較の手順をまとめる。自動48枠の成立を初見の発見性や児童の理解の合格へ置き換えない。既存台帳の未実施状態を追認で変更しない。
