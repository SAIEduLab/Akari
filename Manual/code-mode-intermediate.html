コードモード 中級

画面のものから、プログラムを読む

作品画面で部品を選ぶと、表示された本文をすぐに編集できます。今のできごとが空で、別のできごとに本文があれば、その本文を開きます。

「コード」「ブロック」で表示を切り替えます。別の本文を編集・追加するときは「できごと」で見出しを選び、その見出し自体も文として直接編集できます。「すべてのコード」で開始・クリック・知らせを受け取ったときなどの全文を一覧にでき、一覧の「この本文を編集」で編集へ進めます。一覧を閉じるときは、一覧表示中だけ現れる「本文の編集に戻る」を押します。

共通の「手順」「答えを求める」定義は画面のコードです。呼び出す側の一覧にも本文が表示されます。部品を選んでいるときに現れる「画面のコード」から、使っていない定義も開けます。画面を選んでいるときは「すべてのコード」を使います。書き方エラーがある本文は、入力したコードのまま表示されます。

初級で覚えた「命令・もし・回数くり返し・変数」を土台に、条件式、条件反復、リスト、状態、知らせ、画像・音、手順と答えを求める定義の入口まで広げます。

目次 1. 中級でできること 2. 条件式を組み立てる 3. 条件でくり返す・待つ 4. リストを使う 5. 状態を読み取る 6. できごとを使い分ける 7. 知らせと質問 8. 画像・衣装・背景・音 9. ペンで描く 10. 計算を使う 11. 手順・答えを求めるを作る 12. 調べながら実行する 13. 中級作品の組み立て方

1. 中級でできるようになること

初級では、命令を上から順に並べ、回数くり返し・もし・変数を使いました。中級では、作品を「状況に応じて動くプログラム」へ発展させます。

条件を組み合わせる比較、かつ、または、否定を使います。
終わるまでくり返す回数ではなく状態を見ながら続けます。
複数の値を扱うリストを作り、1つずつ処理します。
画面の状態を読む位置、キー、マウス、衣装、背景などを値として使います。
処理を連携する知らせや質問で別の処理とつなぎます。
処理をまとめるよく使う処理を「手順」や「答えを求める」定義として登録します。

2. 条件式を組み立てる

例の準備：「データ」で点数と残り時間を点・秒の単位付き数として作り、できごとの見出し「ねこがクリックされたとき、」を置きます。以下は仕様上の条件作文例で、実行結果のPASSを示すものではありません。

「もし」や条件反復で使う条件は状態や比較を表す述語として書きます。条件値を保存するときは「条件の答え（あてはまる／あてはまらない）」の値を使います。

比較

意味書き方の例
以上点数が10点以上
以下残り時間が0秒以下
より大きい横位置が100より大きい
より小さい点数が100点より小さい
同じ答えが条件の答え（あてはまる）と同じ
違う受け取った知らせが「終了」と違うなら

条件を組み合わせる

二つの条件は「で」（両方）または「か」（どちらか）で結びます。接続は述語に合わせて活用し、結果が決まった時点で不要な側を評価しません。三つ以上・入れ子・混合は括弧で範囲を示します。

複数条件の例
もし点数が10点以上で、残り時間が0秒より大きければ、
  ねこは「クリア！」と言う。
条件が長くなったら、入力候補で比較や論理式の標準形を確認しながら組み立てると安全です。

3. 条件でくり返す・待つ

回数が最初から分からない処理では、条件を見ながら続ける反復を使います。

条件が成り立つあいだ

点数を0点にする。
点数が3点より小さいあいだ、くり返す。
  点数を1点増やす。
点数の値を言う。

条件が成り立つまで

「空白」キーが押されるまで、くり返す。
  0.1秒待つ。

「まで」は、条件が成り立った時点で終わります。最初から成り立っていれば、中の本文は1回も実行されません。

待つだけにする

「空白」キーが押されるまで待つ。
ねこは「押されました」と言う。
待っている間も、ほかの処理は進みます。 あるキャラクターが待っていても、別のクリック処理やほかの実行中処理まで全部止まるわけではありません。

4. リストで複数の値を扱う

リストは、複数の値を順番に保存するデータです。上部の「データ」でリストを作ってから使います。

追加・変更・挿入・削除

リスト名を「名前一覧」にし、空の状態から始めます。次の例は順番に操作を試すもので、最後に空になります。各要素の例を試す前には、値を入れ直してください。

名前一覧に「あかり」を追加する。
名前一覧の1番目を「ひかり」にする。
名前一覧の1番目に「ほたる」を挿入する。
名前一覧の1番目を削除する。
名前一覧を空にする。

番号は1から数えます。範囲外の読込・更新・削除はエラーになります。挿入だけは、末尾の次の番号も使えます。

1つずつ処理する

持ち物の中身を先頭から一つずつ見て、次のことを行う。
  この中では、今見ているものを【品物】と呼ぶ。
  品物の値を言う。

「項目」は、その反復の中だけで読める名前です。反復を始めた時点のリストを複製して順番に処理するため、途中で元のリストを変更しても、その反復の順番と内容は変わりません。

途中で抜ける・次へ進む

このくり返しを終える。
この回の残りをとばして、次の回へ進む。

この二つは使い分けを示す例です。そのまま続けて置かず、くり返しの本文の中へ必要な方を入れます。入れ子の反復では、最も内側の反復に作用します。

音音量、音程
その他タイマー、クローンである
状態を使う例

イベントのときだけ読める値

6. 「できごと」を使い分ける

同じ部品でも、できごとごとに別の本文を持てます。作品を大きくするときは「何が起きたら、どの本文を動かすか」を分けて考えると整理しやすくなります。

できごと使いどころ
作品を動かしたとき、ねこは、作品の開始時
ねこがクリックされたとき、対象へのクリック
「空白」キーを押すたびに、ねこは、新しい押下の出来事
「出発」という知らせを受け取ったとき、ねこは、指定した知らせの受信
背景が変わったとき、ねこは、場面転換
入力欄1の中身が変わったとき、入力欄の変更
ねこの分身が作られたとき、その分身自身の開始処理
開始時には画面、その後に部品の登録順で開始処理が作られます。複数の処理は命令単位で進み、待っている処理以外は動き続けます。

7. 「知らせ」で処理同士をつなぐ

知らせを使うと、ある本文から画面と全個体へ合図を送り、それぞれの「知らせを受けたとき」を起動できます。

知らせる側
「開始」と知らせる。
「出発」という知らせを受け取ったとき、ねこは、
もし受け取った知らせが「開始」と同じなら、
  ねこは「受け取りました」と言う。

受け手の終了を待つ

みんなに「出発」と知らせる。
その知らせを受けて始めたことが全部終わるまで待つ。

この形では、その通知で直接起動した各処理の終了を待ちます。

質問する

「名前は何ですか」とたずねて、答えを待つ。
答えを【名前】という変数に入れる。
【名前】の値を言う。

質問は1つずつ表示され、「答え」は質問した処理ごとに保持されます。

知らせは自分自身にも届きます。「知らせを受けたとき」で無条件に同じ知らせを送り直すと、再通知が続くので注意します。

8. 画像・衣装・背景・音を使う

素材を使うと、標準キャラクターだけでなく、自分で用意した画像や音を作品へ入れられます。

素材の追加

  • 画像を置く：画像を新しいキャラクターとして追加します。
  • 音声を追加：音をすぐ追加します。
  • 画像・音声を管理：背景、衣装、音をまとめて管理します。

画像はPNG/JPEG/WebP、音はMP3 / WAV（PCM）/ M4A（AAC-LC）/ FLAC / Ogg Opusを使えます。音は60秒・2チャンネルまでで、元ファイル12MiB、取り込み後6MiBが上限です。M4AはAAC-LCの単一音声、OggはOpusが対象です。音声のデコードに対応したブラウザーを使ってください。

背景・衣装

下の例では、先に背景「空色」と、選んだキャラクターの衣装「星」を用意します。背景や衣装の名前は、登録した名前へ置き換えても構いません。

背景を「空色」にする。
次の背景にする。
前の背景にする。
衣装を「星」にする。
次の衣装にする。
前の衣装にする。

音

440Hzの音を0.2秒鳴らし始める。
440Hzの音を0.2秒鳴らす。
音量を50％にする。
音程を1段階上げる。
すべての音を止める。

「鳴らし始める」は音を開始して次へ進みます。「鳴らす」はその音が終わるまで現在の処理だけを待たせます。

音「ベル」を鳴らす。

先に音声素材を追加し、名前を「ベル」にしてから試します。追加した音はこのように名前で指定できます。

9. ペンで軌跡を描く

キャラクターのできごとの見出しを「ねこがクリックされたとき、」にし、その本文へ次の文を入れます。止めているときに画面の内側へ置き、方向を0度にすると、右・下・左・上へ進んで四角が描けます。画面に収まらなければ歩数を小さくします。

部品を動かしながらペンを使うと、移動の軌跡を描けます。

ペンの色を「青」にする。
ペンの太さを3にする。
ペンを下ろす。
4回くり返す。
  100歩動く。
  右に90度回る。
ペンを上げる。

ほかに、スタンプを押す。、描いた線とスタンプを消す。 も使えます。

10. 計算と組み込み求値を使う

数や文字を加工するときは、演算や用意された計算を式として使います。

代表的な組み込み求値

数乱数、余り、四捨五入、切り上げ、切り捨て、絶対値、平方根
三角関数・対数正弦、余弦、正接、逆正弦、逆余弦、逆正接、自然対数、常用対数、指数
まとめる最小、最大
変換・文字数、文字、つなぐ

乱数と余りは引数2個、四捨五入など多くは1個、最小・最大は1個以上、つなぐは2個以上の引数を取ります。三角関数の角度は度です。

式の書き方は入力候補から入れるのが確実です。中級では「値を作るものは命令ではなく式として使う」という区別を意識します。

11. 手順と答えを求める定義を作る 入口

よく使う命令のまとまりは「手順」に、値を返す処理は「答えを求める」定義にできます。どちらも引数名と本文を付けて登録します。

手順：命令をひとまとまりにする

例では「ジャンプ」という手順に「高さ」を渡します。手順の本文は呼び出した対象で動きます。

ジャンプという手順（受け取る値：高さ）
縦位置を縦位置－高さにする。
0.2秒待つ。
縦位置を縦位置＋高さにする。

手順を登録した後、呼び出す本文には次のように書きます。

高さを30として、【ジャンプ】という手順を行う。

答えを求める：値を返す

定義の表示名は「答えを求める」です。数だけでなく文字や条件の答えなども返せます。末尾では返す値を答えと明示します。

合計という答えの求め方（受け取る値：数一覧）
この中だけで使う変数【合計値】を作り、最初は0にする。
数一覧の中身を先頭から一つずつ見て、次のことを行う。
  この中では、今見ているものを【数】と呼ぶ。
  合計値に【数】を足す。
合計値を答えとして返す。
（数一覧を［1、2、3］として、【合計】で求めた答え）を言う。

値を求める定義は局所データ、条件、反復、ほかの値を求める定義の呼出しを使えます。外部データの読取りや乱数も扱いますが、外部データの変更、発言、質問、通知、待機、音、分身、停止、手順呼出しはできません。

定義は「保存」を押すまで下書きです。 見出し、受け取る値、本文を確認し、登録してから作品全体を保存します。これらの作文例は仕様例で、実装試験の合格を示すものではありません。

12. 実行を止めずに調べる

表示を「くわしく」にすると、デバッグ用の操作も使えます。

⏸ いったん止める現在の実行状態を保ったまま一時停止します。
▶ 続ける一時停止したところから再開します。
1命令ずつ命令単位で実行位置を進めます。待ち時間そのものは早送りされません。
動きのようす実行中の状態や出力を確認します。

実行中・一時停止中は本文を変更できませんが、コードとブロックを切り替えて同じ実行位置を確認できます。

実行エラーが起きると一時停止します。失敗した処理は終了するため、修正するときは「■ 止める」で編集へ戻り、直したあと改めて実行します。

13. 中級作品の組み立て方

中級では、1本の長い本文へ全部を書くより、役割を分けた方が作りやすくなります。

開始で初期化→ 入力をできごとで受ける→ 変数・リストを更新→ 知らせで連携→ 見た目・音を更新

例：簡単なゲーム

  1. 「作品を動かしたとき、」の見出しの本文で点数や背景を初期化する。
  2. キャラクターの「ねこがクリックされたとき、」の本文で点数を増やす。
  3. 点数が一定以上になったら「クリア」と知らせる。
  4. 画面の「知らせを受け取ったとき、」の本文で、背景変更や音を鳴らす。
  5. 繰り返し使う命令は「手順」にまとめる。
中級の到達点： 条件・反復・リスト・状態・複数のできごと・知らせ・素材・自作の手順を組み合わせ、処理を役割ごとに分けて作品を構成できれば、中級の中心内容は身に付いています。

文章の取り込み先を確認する

複数のキャラクターやできごとを含む文章を貼り付けても、入力中は今の本文を保ちます。表示された既存の動きと追加先を確認し、「既存を残して追加」で確定します。既存本文はそのままで、別のできごとは対応する本文に追加されます。違いがある場合は本文を比較して取り消せます。今の本文を変更する場合は、先頭の見出しが今の対象・できごとと一致し、ほかの既存本文と衝突しないときだけ「この本文を変更して取り込む」を選べます。表示された変更前後を確認してください。前の見出しに依存する文章を安全に分けられない場合は確定しません。取消は入力前へ戻し、確定後は「元に戻す」「やり直す」で取り込み全体を戻せます。同じ内容を意図して別々に登録した本文は、それぞれ実行します。
