コードモード 初級

日本語の文を1行ずつ書いて、キャラクターを動かし、条件やくり返しを使い、作品を保存するところまでを学びます。プログラミングが初めてでも、上から順に試せる構成です。

目次 1. 最初の1行 2. コード画面の見方 3. 基本の書き方 4. 命令を増やす 5. 入力候補を使う 6. くり返す 7. 条件で分ける 8. 変数を使う 9. コメントを書く 10. エラーを直す 11. 実行・保存 12. ブロックとの関係 13. 短い書き方も

1. 最初の1行を書いてみよう

まず、キャラクターをクリックしたら10歩動く作品を作ります。

  1. キャラクターを置く。
    道具箱から、マスコットなどの標準キャラクターを作品の画面へ追加します。
  2. 動かすものを選ぶ。
    コード欄の上にある「動かすもの」で、追加したキャラクターを選びます。
  3. できごとを選ぶ。
    「できごと」で「クリックしたとき」を選びます。
  4. コードを書く。
    本文へ次の1行を入力します。
クリックしたとき
10歩動く。
  1. 「▶ 動かす」を押す。
    作品の画面でキャラクターをクリックします。
  2. 動いたら成功。
    「■ 止める」で編集へ戻ります。
あかりでは、できごとの名前をコード本文には書きません。 「動かすもの」と「できごと」は画面上で選び、その組合せに対する本文だけを書きます。

2. コード画面の見方

動かすもの：キャラクター1 できごと：クリックしたとき
コードを整える コード ブロック 入力を取り消す
10歩動く。 「こんにちは」と言う。
✓ 書き方をチェック中　／　入力候補
動かすものどの画面・部品・キャラクターの処理を書くかを選びます。
できごといつ処理を始めるかを選びます。開始、クリック、キー、知らせなどがあります。
コード本文日本語の命令を書く場所です。原則として1行に1つの命令を書きます。
入力候補使える命令・値・名前を検索して、本文へ挿入できます。

最初はコード表示です。「コード」と「ブロック」は同じ本文の二つの見せ方で、実行できる機能や実行結果は変わりません。

3. まず覚える書き方

1行に1命令命令は基本的に1行ずつ書きます。
句点「。」は省略できる入力時はなくても構いません。「コードを整える」と標準形では句点が付きます。
文字は「」で囲む文字列は「こんにちは」のように、かぎ括弧で囲みます。
字下げは半角スペース「もし」や「くり返し」の中身は深く字下げします。タブと全角空白は使いません。
上から順に実行同じ本文では、基本的に上の命令から順に進みます。
空行は使える読みやすくするための空行を入れられます。

「。」はあってもなくてもよい

次の2行は入力としてどちらも使えます。

10歩動く
10歩動く。

「コードを整える」を使うと、標準的な書き方へ整えられます。

文字を書くとき

「こんにちは」と言う。
「スタート」と知らせる。
文字の外側に使うのは、日本語のかぎ括弧「 」です。文字の中に同じかぎ括弧を入れるための特別な書き方はありません。文字の中には「 」を入れずに書きます。

4. 命令を増やしてみよう

1行動いたら、次は複数の命令を上から順に実行させます。

キャラクター ／ クリックしたとき
10歩動く。
右に15度回る。
「動いたよ」と言う。
1秒待つ。
10歩動く。

この本文では、クリックすると「動く → 回る → 話す → 待つ → 動く」の順に進みます。

初級で使いやすい命令

やりたいこと例
前へ動く10歩動く。
右へ回る右に15度回る。
位置を決める横100、縦50の位置へ行く。
言葉を表示する「こんにちは」と言う。
少し待つ1秒待つ。
隠す・見せる隠れる。 ／ 現れる。

5. 分からない命令は「入力候補」で探す

すべての文型を暗記する必要はありません。コード表示の「入力候補」を開くと、命令・値・名前を検索できます。

  1. 「入力候補」の見出しを押して開きます。
  2. 検索欄へ「動く」「待つ」「点数」などの言葉を入れます。
  3. 候補を押して本文へ入れます。
  4. 候補内の数値や文字は例なので、目的に合わせて書き換えます。

候補が多いときは「前」「次」でページを切り替えられます。「使えないものも表示」を選ぶと、現在の対象や場所では使えない候補と、その理由も確認できます。

おすすめの使い方： 文型を思い出せないときは、推測して書き続けるより入力候補から入れる方が確実です。名前や現在の場所に合わせた候補も表示されます。

6. 同じことをくり返す

同じ命令を何行もコピーする代わりに、くり返しを使えます。

10回くり返す
次のことを10回くり返す。
  10歩動く。
  右に15度回る。

1行目が「くり返しの始まり」です。その下の2行を半角スペースで深く字下げすると、その2行がくり返されます。

字下げが範囲を決めます。 あかり 1.0.0 では「ここまで」とは書きません。字下げを元へ戻すと、くり返しが終わります。

くり返しの後に続ける

次のことを3回くり返す。
  10歩動く。
「終わりました」と言う。

最後の「言う」は字下げしていないため、3回のくり返しが全部終わったあとに1回だけ実行されます。

7. 条件によって動きを変える

この例の準備：上部の「データ」で、作品全体の変数「点数」を先に作ります。数の初期値を10にし、キャラクターの「クリックしたとき」に下の例を入れます。動かしてクリックすると「10点以上です」と表示されます。止めて初期値を9に変えると、下の分岐例では別の言葉が出ます。変数の説明は次の章です。

「もし」を使うと、条件が成り立つときだけ命令を実行できます。

もし
もし 点数が10以上なら、次のことをする。
  「10点以上です」と言う。

条件が偽のときにも別の処理をしたい場合は、「そうでなければ」を続けます。

もし／そうでなければ
もし 点数が10以上なら、次のことをする。
  「10点以上です」と言う。
そうでなければ、次のことをする。
  「まだ10点未満です」と言う。
「そうでなければ」は、直前にある同じ字下げ位置の「もし」と組になります。

8. 変数で値を覚える

点数や回数など、変わる値を覚えておくには変数を使います。まず上部の「データ」で変数を作ります。

例：クリックするたびに点数を増やす

「データ」で作品の変数「点数」を作ったら、画面の「開始したとき」に初期値を入れます。

画面 ／ 開始したとき
点数を0にする。

次に、キャラクターの「クリックしたとき」で増やします。

キャラクター ／ クリックしたとき
点数に1を足す。
点数と言う。

これで、作品を始めると点数が0になり、キャラクターをクリックするたびに1ずつ増えます。

変数の基本4つ

値を入れる点数を0にする。
増やす点数に1を足す。
値として使う点数と言う。 のように、名前を値として使えます。
条件に使う点数が10以上 のように比較できます。

9. コメントを残す

※ から行末まではコメントです。実行されず、自分やほかの人への説明として残せます。

※ クリックすると右へ進む
10歩動く。

10歩動く。 ※ ここで2回目

空行とコメント行は、「もし」や「くり返し」の範囲そのものを変えません。

10. うまく動かないとき

まず「作品チェック」

「作品チェック」は、どの本文の何行目に、どんな問題があるかを表示します。実行する前に見つけられる書き方・名前・対象の誤りがあります。

よくある初級のミス

症状確認すること
「もし」や「くり返し」でエラーになる中の命令を半角スペースで字下げしているか確認します。タブ・全角空白は使いません。
文字が正しく読まれない文字を日本語の「」で囲んでいるか確認します。
変数名でエラーになる「データ」で変数を作っているか、名前が合っているか確認します。
ある命令だけ使えないその命令が現在選んでいる対象で使えるか、入力候補の「使えないものも表示」で理由を確認します。
ブロック表示へ切り替えられない本文に書き方エラーがあります。コード表示でエラーを直すと切り替えられます。

「コードを整える」を使う

文法として読める本文は「コードを整える」で標準形へ整えられます。句点が付き、字下げは1段につき半角スペース2個になります。

11. 実行して、作品を保存する

コードを書く→ 作品チェック→ ▶ 動かす→ ■ 止める→ 保存

実行

  • ▶ 動かす：作品を実行します。
  • ■ 止める：実行を終了して編集へ戻ります。
  • 実行中・一時停止中は本文を変更できません。

保存

「保存」は、あとで編集を続けられる .akari.md の作品ファイルを作ります。開き直すときは、あかりを開いてから「開く」で読み込みます。

作業内容は自動保存されません。残したい作品は、終了前にファイルとして保存します。

完成した作品を書き出す

「書き出し」を使うと、編集画面なしで作品を動かす単体HTMLを作れます。書き出しには作品全体の文法・参照の検査への合格が必要です。

12. コードとブロックは同じ本文

切り替えるだけでは書いた言葉を整え直しません。値を変えたときはその場所を直し、命令を追加するなど構造を変えたときは、必要な範囲を書き直します。「コードを整える」は自分で標準の書き方へそろえたいときの操作です。

コードモードで書いたプログラムとブロックモードで組んだプログラムは、別々には保存されません。どちらも同じ日本語本文を編集しています。

  • コードからブロックへ切り替えても、実行結果は変わりません。
  • 表示を切り替えただけでは、本文や編集履歴は変わりません。
  • コードに文法エラーがあると、ブロック表示への切替は保留されます。
  • 保存されるプログラムは日本語本文で、ブロック専用の別データではありません。
初級の到達点： 「動かすもの・できごとを選ぶ → 日本語の命令を書く → くり返し・もし・変数を使う → 作品チェック → 実行 → 保存」までできれば、コードモードの基本は身に付いています。

13. 慣れたら、短い書き方も

あかりは、決まったいくつかの書き方を同じ意味で受け取ります。何でも自由な日本語で書けるわけではありません。まずはこの冊子の書き方と「入力候補」を使いましょう。

一つの命令なら、条件と同じ行へ

作品の変数「点数」を作り、キャラクターの「クリックしたとき」で試します。上の例と下の例は同じ動きです。一度に両方入れず、一つずつ試してください。

もし 点数が10以上なら、次のことをする。
  「やったね」と言う。
そうでなければ、次のことをする。
  「あと少し」と言う。
もし 点数が10以上なら、「やったね」と言う。
でなければ、「あと少し」と言う。

「でなければ」は次の行へ書きます。同じ行に命令をいくつも続けたり、その中へさらに「もし」を入れたりはできません。二つ以上の命令を入れるときは、字下げの形を使います。

「何を」「どこへ」が分かる書き方

この冊子の書き方同じ意味の別の書き方
点数に1を足す。1を点数に足す。
横100、縦50の位置へ行く。縦50、横100の位置へ行く。
右に15度回る。15度右に回る。

「横」「縦」「度」「を」「に」など、役割を表す言葉を落とさないことが大切です。点数を10にするは10へ変えること、点数を10増やすは今の数に10を足すことです。

一行の「もし」へブロックで命令を追加すると、その「もし」は字下げの形へ広がります。「元に戻す」で編集前へ戻せます。
