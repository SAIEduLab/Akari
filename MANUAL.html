あかり マニュアル

画面のものから、プログラムを読む

作品画面で部品を選ぶと、表示された本文をすぐに編集できます。今のできごとが空で、別のできごとに本文があれば、その本文を開きます。

「コード」「ブロック」で表示を切り替えます。別の本文を編集・追加するときは「できごと」で見出しを選び、その見出し自体も文として直接編集できます。「すべてのコード」で開始・クリック・知らせを受け取ったときなどの全文を一覧にでき、一覧の「この本文を編集」で編集へ進めます。一覧を閉じるときは、一覧表示中だけ現れる「本文の編集に戻る」を押します。

共通の「手順」「答えを求める」定義は画面のコードです。呼び出す側の一覧にも本文が表示されます。部品を選んでいるときに現れる「画面のコード」から、使っていない定義も開けます。画面を選んでいるときは「すべてのコード」を使います。書き方エラーがある本文は、入力したコードのまま表示されます。

この総合ガイドは、1.2.0で目指す作文・編集の仕様を紹介します。作例は設計例であり、製品の実装試験や児童による評価を示すものではありません。保存・続きの開き方や詳しい編集は、ブロック・コード初級・中級・上級の各章を参照してください。

マニュアルを選ぶ はじめての作品保存・開く困ったとき 言語仕様を見る

まずはここから

つくる → 動かす → 保存する

「プログラム」は、コンピューターへのお願いを順番に書いたものです。あかりでは、画面に置いたキャラクターなどを、日本語の命令で動かします。

はじめて作る画面の見方保存する続きを開く作品を渡す困ったとき
全部を一度に覚えなくて大丈夫。 まずは下の小さな作品を一つ作ります。ブロックとコードの詳しい説明は、その後の4冊へ進んでください。

最初の作品

クリックしたら、ねこが右へ動く

初めて開くとブロック表示になります。コード／ブロックを自分で選ぶと次回にも使います。「かんたん／くわしく」とは別の設定です。初めて開いた作品と「新しく作る」は、開始本文が空です。対象とできごとを選び、命令を追加します。お手本の選択欄には①ダンス、②花もよう、③星のゲームがあります。「お手本を開く」で確認が出ます。「はい」で今の作品をリセットして読み込み、「キャンセル」で作りかけの作品を保ちます。「お手本のヒント」で、数値変更やブロックの交換・並べ替え・追加・削除を試しましょう。以下では自分でクリックに反応する作品を作ります。今の作品を残したい場合は、先に「保存」を押しましょう。

  1. あかりを開く
    あかり本体を開きます。続きから作るときは「開く」で保存済みの作品ファイルを読み込みます。実行中なら「■ 止める」で編集へ戻ります。
  2. キャラクターを置く
    ブロック表示では右側の「＋ キャラクター・部品をふやす」、コード表示では左側の道具箱からマスコット、だんご、星などを選びます。作品の画面に置かれたキャラクターを選びます。だんごは透過した原画を180×180で表示し、作品の保存や単体HTMLへの書き出しでも同じ画像を使います。
  3. 「何を」「いつ」動かすか選ぶ
    できごとの見出しは「ねこがクリックされたとき、」のように、いつ・だれがを文として示します。本文は対象や動きを書きます。
  4. 文を一つ入れる
    「コード」を選び、本文へ下の1行を入れます。できごとの見出しは本文の命令とは別に見える形で編集します。 
    ねこは右へ10歩動く。
    ブロック表示でも対象・方向・量を一つの文として組み立てます。
  5. 動きを確かめる
    「▶ 動かす」を押し、作品の画面でキャラクターをクリックし、文に書いた動きと画面の変化を比べます。仕様例は実装確認前の設計を示します。「■ 止める」で編集へ戻ります。
  6. 作品を保存する
    「保存」を押します。ダウンロードされた .akari.md が、続きを作るための作品ファイルです。
少し変えてみよう。 文の「10歩」を「30歩」に変え、対象・方向・量のどこを編集したかを確認します。動作結果は1.2.0実装後の試験で確かめます。

画面は「置く・選ぶ・命令する」

置く：作品の画面文字やキャラクターを置く場所。止めているときに動かして位置を決めます。
選ぶ：動かすもの・できごとどの部品が、何をきっかけに動くか選びます。
命令する：本文上から順に動きを書きます。「コード」と「ブロック」は同じ本文の見せ方です。

「せってい」では部品の名前・位置・大きさ・色などを変えます。「データ」では点数などを覚える入れ物を作ります。表示は「かんたん」「くわしく」の2段階です。「元に戻す」「やり直す」はどちらでも表示し、使える履歴がないときや実行中は無効になります。表示を変えても、作品の内容は変わりません。コード表示の「せってい」「動きのようす」は通常の見出しで、ブロック表示では折り畳めます。

実行と編集を切り替える

「▶ 動かす」で作品を実行し、「■ 止める」で編集へ戻ります。実行中や一時停止中は本文を変更できません。開始の命令が終わっても、止めるまではクリックなどを受け付けます。

動かす前には「作品チェック」で、書き方や名前の問題を確認できます。実際の数や値が原因のエラーは、動かしたときに見つかることもあります。

作品画面を拡大・縮小する

コード・ブロックのどちらでも、作品画面の見出しにある「−」「倍率」「＋」「全体」で表示を調整できます。最初は幅と高さの両方が収まる倍率で表示します。「−」「＋」は10ポイントずつ、10〜200%の範囲で変更します。倍率のボタンを押すと100%、「全体」を押すと表示枠に収まる倍率に戻ります。拡大してはみ出した部分はスクロールで確認できます。モードを切り替えても倍率の選択を引き継ぎ、全体表示中は表示枠の大きさに合わせ直します。実行中も倍率を変更できます。倍率は表示だけの設定で、作品の大きさ・配置・コード・編集履歴を変えず、保存ファイルや書き出したHTMLには記録しません。

大切な作品を残す

「保存」と「書き出し」は何が違う？

目的に合う残し方
したいこと使う操作できるもの
あとで続きを作りたい保存.akari.md。あかりの「開く」で読みます。
編集画面なしで作品を動かしたい書き出し.html。ブラウザーで開いて動かします。
前回の作業へ戻りたい「開く」で作品ファイルを読み込む最後に「保存」した内容から再開します。

保存の手順

  1. 入力途中の欄を完成させます。「手順・答えを求める」の下書きがある場合は、その画面の「保存」で先に登録します。
  2. 上部の「保存」を押します。ブロック表示のままでも保存できます。
  3. ブラウザーのダウンロード一覧や保存先で、作品名の付いた .akari.md を確認します。
  4. 作品を直したら、もう一度保存します。同じ名前のファイルが増えた場合は、更新日時を見て新しいものを確認します。
作品ファイルの本文を、別のアプリで書き換えないでください。 ファイルには、読むための本文と、あかりに戻すためのデータが入っています。直すときはあかりの中で編集し、保存し直します。

書き方に間違いがある作りかけの本文も、作品の構造・素材・容量などの条件を満たせば保存できます。「動かす」「書き出し」は、作品全体の書き方・名前・対象の検査に合格してから行います。

保存した作品の続きを作る

「開く」をおすと、まだほぞんしていない変更があるときだけ、先にたしかめます。「ほぞんせずに開く」で作品をえらぶ画面へ進みます。「キャンセル」で今の作品へもどります。作品をえらぶのをやめたり、読みこめなかったりしたときも、今の作品はのこります。

  1. あかり本体を開く
    作品ファイルを読むアプリではなく、Akari1_2_0.html をブラウザーで開きます。
  2. 今の作品を残す
    作業中の作品を残したければ、先に「保存」を押します。未保存の編集を捨てる確認には、内容を確かめて答えます。
  3. 「開く」で選ぶ
    保存した .akari.md を選びます。本文や素材が戻ったら、「動かすもの」「できごと」を選んで続きを作れます。

読み込みの問題が出たら、表示されたエラーを確認します。本文と復元用データが一致しない場合は「F512」です。読み込みに失敗したファイルで、今の作品を置き換えません。

終了する前に保存する

作業内容と未登録の手順・答えを求めるの下書きは、この端末・ブラウザー内に自動保存されます。次回起動時に記録の検証に通れば復元を選べます。自動保存が利用できない場合や端末の故障に備え、残したい作品は「保存」で作品ファイルを保存し、ダウンロードできたことを確認してください。

「手順・答えを求める」の下書きは、先にその画面の「保存」で登録してから、作品全体を保存します。

完成した作品を動かしてもらう

「作品のはじめ方をえらぼう」で、見本を見てえらびます。「▶ はじめるボタンをつける」は、おすとはじまり、途中で止められます。「作品をすぐにはじめる」は、開くとはじまり、作品のまわりにボタンやわくをつけません。作品の中に作ったボタンはのこります。音が出る作品は、中央の「ここをおしてはじめる」をおすとはじまることがあります。もう一度動かすときは、そのページを読みこみ直します。「キャンセル」では書き出しません。

  1. あとで直せるよう、先に .akari.md を保存します。
  2. 「作品チェック」で問題を直します。「手順・答えを求める」の下書きも登録します。
  3. 「■ 止める」で編集へ戻り、「書き出す」を押して、作品のはじめ方をえらびます。
  4. できた .html を開き、えらんだはじめ方で動くことをたしかめます。

書き出したHTMLには、動かすための仕組みと使っている素材が入っています。この1ファイルで動作し、編集画面や隣の素材ファイルを必要としません。インターネットがない場所でも動かせます。

直すためのファイルも残しましょう。 書き出したHTMLには編集機能がありません。続きを作るための .akari.md と、遊ぶための .html を分けて残します。

ネットにつながずに使う準備

  • 作る：あかり本体を保存します。Akari1_2_0.html 単体をブラウザーで開けば編集・実行できます。
  • 続きを作る：本体に加えて、自分の .akari.md を持っていきます。
  • 完成作品を動かす：書き出した .html を持っていきます。
  • 説明も読む：この MANUAL.html と Manual フォルダーを同じ配置で保存します。入口や仕様のリンクも使うなら、index.html、README.md、LANGUAGE.md、AUDIT.md、LICENSE も一緒に残します。

あかり本体は、外部のサービスや外部スクリプトへ接続しません。GitHubなどへの案内リンクを開く場合は、インターネット接続が必要です。

困ったときに

よくあるつまずき

「動かす」を押しても、キャラクターが動かない

「ねこがクリックされたとき、」の本文に命令を書いた場合は、実行を始めた後にキャラクターをクリックします。「動かすもの」と「できごと」が、命令を書いた場所と合っているか確認しましょう。

命令や変数が使えない

「作品チェック」の場所・行・理由を見ます。変数は先に「データ」で作ります。名前と文字の違いにも注意してください。点数 はデータの名前、「点数」 はその文字です。命令が対象に合わない場合は、入力候補や道具箱に出る理由を確認します。

保存やモード切替ができない

空欄や「－」だけなど、入力途中の欄が残っていないか確認します。入力を完成して確定するか、取り消します。日本語を変換している途中なら、まず変換を確定してください。「手順・答えを求める」の下書きはその画面の「保存」で登録します。

ブロックに切り替えられない

文の書き方が読めないときは、コード表示のままになります。「作品チェック」を見て、かぎ括弧や字下げなどを直します。名前が未登録なだけの問題と、文法の問題は別です。

保存したファイルが見つからない

ブラウザーのダウンロード一覧を開き、作品名や .akari.md を探します。あかりの「未保存」表示が消えても、ダウンロードが端末に残ったかは保存先で確認してください。

書き出せない・作品を開けない

画面に出たエラーを確認します。書き出しには作品全体の検査が必要です。読み込みではファイルの破損、形式、素材、容量などを確かめます。ファイルの中身を書き換えて直そうとせず、保存した元のファイルを確認してください。

音が聞こえない・途中で止まった

音を使う場合は、作品の開始操作を行い、端末と作品の音量を確認します。エラーで一時停止した場合は、場所と理由を見て「■ 止める」で編集へ戻り、直してから再実行します。

画面がせまく、ブロックが見えない

「見わたす」で本文全体を見ます。余白をドラッグして上下左右へ移動でき、「－」「＋」で大きさを変えられます。「作業台を広く」で作品の画面をたたみ、「画面も見る」で戻せます。

マニュアルと仕様書の役割

マニュアルは「どう使うか」を学びやすく説明する案内です。詳しい文法・意味・保存形式・制限は LANGUAGE.md が正本です。検査の項目と合格条件は AUDIT.md が正本です。

Akari1_2_0.html あかり本体。ブラウザーで編集・実行します。
LANGUAGE.md 操作・文法・意味論・実行モデル・制限の詳細仕様です。
README.md 公開リポジトリの概要と主要ファイルへの入口です。
コードとブロックは別の言語ではありません。 どちらも同じ日本語本文を編集します。表示方法を切り替えても、使える言語機能や実行結果は変わりません。

迷ったときの最短ルート

  1. まず Akari1_2_0.html を開いて実際に触る。
  2. 操作が分からなければ、使っているモードのマニュアルを見る。
  3. 書き方が分からなければ「あかり」の「入力候補」またはブロックの道具箱で探す。
  4. 動かない場合は「作品チェック」で場所・行・理由を確認する。
  5. 細かい仕様や制限を確認したい場合は LANGUAGE.md を参照する。

部品を複製する・絵を描く

部品を選び、コード表示では設定欄、ブロック表示では部品一覧の直下にある「見た目のコピー」を押すと、見た目・サイズ・衣装・個体データを引き継いだ別の部品が増えます。コードは含みません。同じ場所の「この部品を消す」で削除でき、ブロック表示では設定欄を開く必要はありません。「元に戻す」で取り消せます。

「画像を置く」の下の「🎨 お絵かき」で、透明な500×500ピクセルの画面を開きます。ペン・消しゴム・塗りつぶし・直線・四角・だ円（長い丸）、色と「線の太さ」、元に戻す・やり直すが使えます。四角・だ円は「ふちだけ」／「塗りつぶし」を選べます。ます目は透明な部分の目印で、保存する絵には入りません。

「決定して置く」で透明な外側の余白を切り、画像キャラクターとして配置します。小さな絵は拡大せず、必要な透明余白で幅・高さを8ピクセル以上にします。作品画面に収まる限り原寸です。描いた画像も作品の保存に含まれます。配置後の描き直しと下書き保存はありません。キャンセル時は描いた絵を捨てるか確認します。

吹き出しの名前を表示する・隠す

対象で「画面」を選び、設定欄の「吹き出し」にある「名前を表示」を切り替えます。ブロック表示で設定欄が閉じているときは、見出しのボタンで開いてください。この設定は作品全体に適用されます。

新しい作品では名前を表示します。チェックを外すと、吹き出しには台詞だけが出ます。台詞や表示時間は変わりません。設定は作品の保存、自動保存からの復元、書き出したHTMLにも反映されます。
